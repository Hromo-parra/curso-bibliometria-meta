Para hacer tus mapas de verdad

Guía de software

Dos programas gratuitos para construir mapas bibliométricos (redes de temas y colaboración): VOSviewer y bibliometrix / Biblioshiny.

⚠️
Verificado con las fuentes oficiales. Los pasos de abajo se contrastaron con la documentación oficial de cada herramienta. Aun así, las versiones cambian: confirma el número de versión exacto en los sitios oficiales enlazados. No incluye capturas porque varían con cada versión.

¿Cuál me conviene?

VOSviewer

Más visual y fácil para empezar; mapas muy vistosos. Necesita Java (o usa la versión en el navegador).

bibliometrix / Biblioshiny

Más completo (muchos análisis en uno). Necesita instalar R, pero se usa con clics.

Para un primer mapa rápido: VOSviewer. Para un análisis bibliométrico completo: Biblioshiny. Las dos son gratis.

1 · VOSviewer

GRATISSitio oficial: vosviewer.com

Programa de escritorio del CWTS (Universidad de Leiden) para visualizar redes: co-ocurrencia de palabras clave, coautoría, co-citación y acoplamiento.

Instalación

  1. Entra a vosviewer.com → sección Download y descarga la versión para tu sistema.
  2. Descomprime y ejecuta el programa. Requiere Java 8 o superior; si no lo tienes, instálalo desde java.com (la propia página de VOSviewer lo indica).
  3. Alternativa sin instalar nada: VOSviewer Online, que corre en el navegador (sirve para ver y compartir mapas).

Cómo hacer un mapa

  1. Pulsa Create (crear).
  2. Elige «Create a map based on bibliographic data».
  3. Carga tu archivo exportado (Web of Science, Scopus, Lens, RIS…) o conéctate por API — las versiones nuevas consultan OpenAlex directamente, sin exportar primero.
  4. Elige el tipo de análisis: co-occurrence (palabras clave) para el mapa de temas; co-authorship para colaboración.
  5. Ajusta el umbral (nº mínimo de ocurrencias) y genera el mapa.
  6. Interpreta: tamaño del nodo = frecuencia · color = clúster · líneas = co-ocurrencia.

Recuerda lo de la Sesión 3: el umbral cambia la red. Documenta cuál usaste.

Tip de calidad: usa un «thesaurus file» para unir variantes de un mismo término (p. ej. «memory» y «memories»); es la causa más común de un mapa de palabras ruidoso.

2 · bibliometrix / Biblioshiny

GRATISSitio oficial: bibliometrix.org

Paquete de R (Aria & Cuccurullo) con una interfaz gráfica llamada Biblioshiny: se usa con clics en el navegador, sin programar. Es «usar R sin escribir código».

Instalación (una sola vez)

  1. Instala R desde r-project.org (CRAN). RStudio (opcional, cómodo): posit.co.
  2. Abre R y ejecuta: install.packages("bibliometrix", dependencies=TRUE)
  3. Luego, para abrir la interfaz: library(bibliometrix) y después biblioshiny()
  4. Se abrirá una página web local con menús de clics. De aquí en adelante, nada de código.

Cómo usarlo

  1. Data → Import: sube tu exportación (Scopus CSV/BibTeX, WoS texto/BibTeX, Lens, Dimensions, PubMed).
  2. Revisa «Main Information» (resumen del dataset: nº de documentos, años, autores).
  3. Explora los menús: producción por año/autor/revista; estructura conceptual (mapa temático, co-word); intelectual (co-citación); social (colaboración); three-fields plot.
  4. Exporta las figuras y tablas que necesites para tu informe.

¿De dónde saco los datos?

Exportas registros de una base y los cargas en la herramienta. Gratis y sin cuenta: OpenAlex y Crossref (APIs). PubMed (biomédico). De pago: Scopus y Web of Science. Siempre documenta la fuente, la fecha y el N.

Otra opción avanzada es CiteSpace (gratuito, requiere Java 8 o superior), más orientada a la evolución temporal de los temas. Descarga: citespace.podia.com.
