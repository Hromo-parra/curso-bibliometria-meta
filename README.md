Sitio web estático (HTML autónomo, sin dependencias).

## Publicar en GitHub Pages
1. Sube estos archivos a la **raíz** del repositorio (todos juntos, sin subcarpetas).
2. Settings → Pages → *Deploy from a branch* → rama `main` → carpeta `/ (root)`.
3. Espera 1–2 min: la URL será `https://<usuario>.github.io/<repo>/`.

La página principal es **index.html**; enlaza a las otras tres por nombre de archivo,
así que los cuatro `.html` deben estar en la misma carpeta.
